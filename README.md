# William Horinek Portfolio

Static, responsive portfolio site prepared for Cloudflare Pages or any simple static host.

## Files
- `index.html` — site content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu and current footer year

## Before deployment
Replace the intentional placeholders in `index.html`:
1. Congressional Market live project URL
2. Resume PDF link (for example `resume.pdf` in this folder)
3. Email link
4. LinkedIn URL
5. GitHub URL

Search for `disabled-link` or `URL placeholder` to find them quickly.

## Cloudflare Pages
This site does not require a build step. Upload/push this folder as the site root and use static hosting with `index.html` as the entry point.
